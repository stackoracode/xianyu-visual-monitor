# 闲鱼视觉监控（Xianyu Visual Monitor）

[English](README.md)

本项目通过**截图 + 本地 OCR** 监控桌面上已经打开的闲鱼网页聊天。目标环境是鲁班猫 RK3588（ARM64，
Ubuntu 20.04，glibc 2.31，XFCE/Xvnc）。程序直接读取现有桌面，不会另开浏览器或桌面会话。

主要功能：

- **监控频率可配置**：先做轻量的逐行像素变化检测，只对变化的行做 OCR，并定期完整复核。
- **手机端已读同步**：在手机上阅读会清除网页角标，这种变化会记为“其他端已读”，不会被当作新消息。
  总未读数仅作参考，从不作为触发条件。
- **历史客户基线**：先在“基线模式”下积累历史客户，再切换到“正式模式”。
- **新客户首次咨询邮件**：每个新观测到的客户只发一封；使用持久化发件箱，支持去重、重试，并有明确的“不确定”状态。
- **持久化去重与重启恢复**：去重键由数据库中的状态推导，重启后不会重复提醒。
- **关键词回复**：支持优先级、模板、排除词、冷却时间、每日上限，否定、敏感话题、附件和截断文本会进入审核；
  有审核模式和自动模式。**默认关闭，必须由管理员输入确认词后才能启用发送。**
- **异常暂停**：遇到登录/验证提示、布局变化、截图失败或无法核实的发送时自动暂停回复，需店主手动恢复。
- **管理后台**（FastAPI + MySQL）：概览/健康、区域校准、客户与身份修正、审核队列、观测记录、通知、规则、回复、设置、脱敏诊断导出。
- **中英文界面**：默认英文，可切换中文；客户消息原文始终按原语言显示。

> **本程序不做的事**：不解析页面 DOM，不使用浏览器调试端口，不拦截网络协议，不调用私有接口，
> 不复制 Cookie，不破解或绕过验证码，也不做反检测改造。它只读取屏幕像素；只有在您启用回复后，
> 才会像人一样点击和输入。

请先阅读 [局限性说明](docs/LIMITATIONS.md)，再按照 [中文部署指南](docs/zh-CN/DEPLOYMENT.md) 部署。
